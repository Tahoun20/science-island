# Science Island

Educational games for Grade 5 Science (Egyptian curriculum, languages track), Chapter 1: Bones and Muscles.

- `index.html`: island map with five stops
- `arm.html`: Arm Mechanic, an interactive arm showing muscles contracting and relaxing
- `quiz.html`: question quests for each lesson (`#lesson1`, `#lesson2`, `#lesson3`) and spaced-repetition review (`#review`)
- `questions.js`: the question bank
- `assets/`: character and background images

Progress is saved in the browser (localStorage) on each device.
